# PathFinder source notes

The opportunity hub should link users to the authoritative source rather than presenting PathFinder as the final authority.

| Source | Validated URL | Use in PathFinder |
|---|---|---|
| NSFAS DHET Bursary Scheme | https://www.nsfas.org.za/content/bursary-scheme.html | Study / bursary opportunity; official eligibility and funding information |
| SAYouth | https://sayouth.mobi/ | Youth jobs, entrepreneurial opportunities, youth programmes, skilling opportunities |
| SAYouth About | https://sayouth.mobi/About | Official context and eligibility information for the SA Youth network |
| SEDA | https://www.seda.org.za/ | Entrepreneurship support source; page extraction was unavailable, so retain the URL and require users to verify current programme details |

Design implication: every curated or future live-search opportunity record must include a non-empty source URL, source freshness timestamp, and a visible Verify / Apply link. If live web search is unavailable, label results as coming from the curated list rather than implying live search occurred.
